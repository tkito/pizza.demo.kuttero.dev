# ピザでも食ってろ.dev

`pizza.demo.kuttero.dev` のランディングページです。

ビルド工程や外部依存はありません。`index.html` を静的ホスティングで公開できます。

## Preview

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。

## Files

- `index.html` — ページ本体
- `styles.css` — レスポンシブデザインとアニメーション
- `script.js` — 年表示とポインター連動エフェクト
- `assets/hero-pizza.webp` — ヒーロービジュアル
- `assets/favicon.svg` — ファビコン
